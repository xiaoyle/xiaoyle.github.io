这里记录我在大学阶段完成和正在推进的个人项目。

## CircuitKit

在线电子入门计算工具集合。

- 技术栈：Next.js / React / TypeScript / Tailwind CSS
- 当前功能：
  - Voltage Divider
  - LED Resistor
  - RC Filter
- 项目状态：持续完善中
- 在线地址：https://circuitkit.netlify.app/

这个项目是我进入大学后进行项目式学习的重要实践，目标是通过真实开发熟悉前端、Git、部署和基础电路知识。
